# Resume

This is a placeholder resume file. Replace this file with your actual PDF resume.

**How to replace:**
1. Save your resume as a PDF file named `resume.pdf`
2. Place it in the `public/` folder of this project (overwrite this file)
3. The "Download Resume" button will automatically serve your PDF

The resume button links to `/resume.pdf`, which Vite serves from the `public/` directory.
